## 1. What Is a Conditional Statement?

A conditional statement is a programming structure that executes specific code depending on whether a condition is true or false.

ধরো, তোমার Ticket Booking API-তে একজন user ticket কিনতে চায়। তুমি যাচাই করবে:

- User logged in কি না
- Ticket quantity সঠিক কি না
- পর্যাপ্ত ticket আছে কি না
- Payment সম্পন্ন হয়েছে কি না

এসব সিদ্ধান্ত নিতে conditional statements ব্যবহার করা হয়।

### Basic Flow

```text
       Check Condition
        age >= 18
             |
       +-----+-----+
       |           |
      true        false
       |           |
   if block     else block
```

Go-তে condition অবশ্যই `bool` value তৈরি করতে হবে। JavaScript-এর মতো arbitrary truthy/falsy value ব্যবহার করা যায় না।

Correct:

```go
if age >= 18 {
    fmt.Println("Eligible")
}
```

Incorrect:

```go
if age {
    fmt.Println("Eligible")
}
```

কারণ `age` একটি integer, boolean নয়।

## 2. The `if` Statement

`if` ব্যবহার করা হয় যখন কোনো condition সত্য হলেই শুধু একটি কাজ করতে হবে।

```go
package main

import "fmt"

func main() {
    age := 22

    if age >= 18 {
        fmt.Println("You are an adult")
    }
}
```

**Output:**

```text
You are an adult
```

### Code Explanation

- `age := 22` — একটি integer variable তৈরি হয়েছে।
- `age >= 18` — পরীক্ষা করা হচ্ছে age ১৮ বা তার বেশি কি না।
- Condition true হওয়ায় `if` block execute হয়েছে।

### Important Rule

Go-তে opening brace `{` condition-এর একই লাইনে থাকবে।

Correct:

```go
if age >= 18 {
    fmt.Println("Eligible")
}
```

Go-এর automatic semicolon insertion-এর কারণে `{` পরের লাইনে রাখলে syntax error হতে পারে।

## 3. The `if...else` Statement

যখন condition সত্য হলে একটি কাজ এবং মিথ্যা হলে অন্য কাজ করতে হবে, তখন `else` ব্যবহার করবে।

```go
package main

import "fmt"

func main() {
    balance := 300

    if balance >= 500 {
        fmt.Println("You can purchase this ticket")
    } else {
        fmt.Println("Insufficient balance")
    }
}
```

**Output:**

```text
Insufficient balance
```

এখানে balance ৩০০, কিন্তু প্রয়োজন ৫০০। তাই `if` condition মিথ্যা এবং `else` block execute হয়েছে।

### Flow

```text
      balance >= 500
             |
       +-----+-----+
       |           |
      true        false
       |           |
 Purchase       Insufficient
  allowed         balance
```

## 4. The `if...else if...else` Statement

একাধিক condition পরীক্ষা করতে `else if` ব্যবহার করা হয়।

### Example: Exam Grading System

```go
package main

import "fmt"

func main() {
    marks := 82

    if marks >= 80 {
        fmt.Println("Grade: A+")
    } else if marks >= 70 {
        fmt.Println("Grade: A")
    } else if marks >= 60 {
        fmt.Println("Grade: A-")
    } else if marks >= 50 {
        fmt.Println("Grade: B")
    } else if marks >= 40 {
        fmt.Println("Grade: C")
    } else {
        fmt.Println("Grade: F")
    }
}
```

**Output:**

```text
Grade: A+
```

### Why Is Condition Order Important?

Consider this example:

```go
if marks >= 40 {
    fmt.Println("Grade: C or above")
} else if marks >= 80 {
    fmt.Println("Grade: A+")
}
```

যদি `marks = 82` হয়, প্রথম condition সত্য হবে। তাই দ্বিতীয় condition পরীক্ষা করা হবে না।

**Senior Engineer Tip:** Range-based conditions এমনভাবে সাজাবে যেন সবচেয়ে গুরুত্বপূর্ণ threshold আগে পরীক্ষা হয় এবং প্রতিটি range স্পষ্ট থাকে।

## 5. Comparison Operators

Comparison operators condition তৈরি করতে ব্যবহার করা হয়।

| Operator | Meaning                  | Example            |
| -------- | ------------------------ | ------------------ |
| `==`     | Equal to                 | `age == 18`        |
| `!=`     | Not equal to             | `status != "paid"` |
| `>`      | Greater than             | `price > 100`      |
| `<`      | Less than                | `quantity < 5`     |
| `>=`     | Greater than or equal to | `age >= 18`        |
| `<=`     | Less than or equal to    | `stock <= 0`       |

### Example

```go
package main

import "fmt"

func main() {
    stock := 0

    if stock <= 0 {
        fmt.Println("Out of stock")
    }

    if stock != 10 {
        fmt.Println("Stock is not 10")
    }
}
```

**Output:**

```text
Out of stock
Stock is not 10
```

মনে রাখবে, `=` assignment-এর জন্য এবং `==` comparison-এর জন্য ব্যবহৃত হয়।

## 6. Logical Operators — `&&`, `||`, `!`

একাধিক condition একসঙ্গে যাচাই করতে logical operators ব্যবহার করা হয়।

### AND — `&&`

সব condition সত্য হতে হবে।

```go
age := 22
hasID := true

if age >= 18 && hasID {
    fmt.Println("Access allowed")
}
```

### OR — `||`

অন্তত একটি condition সত্য হলেই হবে।

```go
isAdmin := false
isModerator := true

if isAdmin || isModerator {
    fmt.Println("Can moderate content")
}
```

### NOT — `!`

Boolean result উল্টে দেয়।

```go
isBlocked := false

if !isBlocked {
    fmt.Println("User is not blocked")
}
```

### Short-Circuit Evaluation

Go-তে `&&` এবং `||` short-circuit evaluation ব্যবহার করে।

```go
if user != nil && user.IsActive {
    fmt.Println("Active user")
}
```

যদি `user == nil` হয়, তাহলে `user.IsActive` পরীক্ষা করা হবে না। ফলে nil pointer dereference এড়ানো যায়।

## 7. Short Statement in `if`

Go-তে `if` condition-এর আগে initialization statement লেখা যায়।

### Example: Convert String to Integer

```go
package main

import (
    "fmt"
    "strconv"
)

func main() {
    input := "123"

    if number, err := strconv.Atoi(input); err == nil {
        fmt.Println("Number:", number)
    } else {
        fmt.Println("Invalid number:", err)
    }
}
```

**Output:**

```text
Number: 123
```

এখানে:

- `strconv.Atoi()` string-কে integer-এ convert করে।
- Conversion সফল হলে `err == nil` হয়।
- Conversion ব্যর্থ হলে `else` block execute হয়।
- `number` এবং `err` variable দুটি `if...else` statement-এর scope-এর মধ্যে থাকে।

যদি `input := "abc"` করা হয়, তাহলে conversion ব্যর্থ হবে।

### Practical Validation

```go
if quantity, err := strconv.Atoi(input); err != nil {
    fmt.Println("Invalid quantity")
} else if quantity <= 0 {
    fmt.Println("Quantity must be positive")
} else {
    fmt.Println("Valid quantity:", quantity)
}
```

বাস্তব HTTP API-তে উপযুক্ত HTTP status code এবং structured response দিতে হবে; শুধু `fmt.Println()` যথেষ্ট নয়।

## 8. The `switch` Statement

একটি variable বা expression-এর বিভিন্ন নির্দিষ্ট value অনুযায়ী আলাদা কাজ করতে `switch` ব্যবহার করা হয়।

### Example: Payment Status

```go
package main

import "fmt"

func main() {
    status := "paid"

    switch status {
    case "pending":
        fmt.Println("Payment is pending")

    case "paid":
        fmt.Println("Payment successful")

    case "failed":
        fmt.Println("Payment failed")

    case "refunded":
        fmt.Println("Payment refunded")

    default:
        fmt.Println("Unknown payment status")
    }
}
```

**Output:**

```text
Payment successful
```

### How It Works

1. `switch status` — status-এর value পরীক্ষা করে।
2. `case "pending"` — value pending হলে এই block চলে।
3. `case "paid"` — value paid হলে এই block চলে।
4. `default` — কোনো case match না করলে চলে।

**Important:** Go-তে matching `case` execute হওয়ার পর স্বয়ংক্রিয়ভাবে পরের case-এ চলে যায় না। এটি JavaScript বা C-এর প্রচলিত switch pattern থেকে একটি গুরুত্বপূর্ণ পার্থক্য।

## 9. Multiple Values in a Single `case`

একই কাজ একাধিক value-র জন্য করতে চাইলে একটি `case`-এ একাধিক value লেখা যায়।

```go
package main

import "fmt"

func main() {
    day := "Friday"

    switch day {
    case "Friday", "Saturday":
        fmt.Println("Weekend")

    case "Sunday", "Monday", "Tuesday", "Wednesday", "Thursday":
        fmt.Println("Working day")

    default:
        fmt.Println("Invalid day")
    }
}
```

**Output:**

```text
Weekend
```

এ ধরনের pattern status, role, category এবং permission-এর মতো logic-এ কাজে লাগে।

## 10. Expressionless `switch`

Go-তে `switch`-এর মধ্যে expression না লিখেও condition ব্যবহার করা যায়। এটি অনেকটা `if...else if`-এর বিকল্প।

```go
package main

import "fmt"

func main() {
    score := 76

    switch {
    case score >= 80:
        fmt.Println("Grade A+")

    case score >= 70:
        fmt.Println("Grade A")

    case score >= 60:
        fmt.Println("Grade A-")

    case score >= 40:
        fmt.Println("Pass")

    default:
        fmt.Println("Fail")
    }
}
```

**Output:**

```text
Grade A
```

প্রতিটি `case` একটি Boolean expression। উপর থেকে নিচে condition পরীক্ষা হয় এবং প্রথম matching case execute হয়।

### `if...else` vs `switch`

| Situation                               | Suitable Choice                           |
| --------------------------------------- | ----------------------------------------- |
| One or two simple conditions            | `if...else`                               |
| Multiple range conditions               | `if...else if` or expressionless `switch` |
| Specific values of one variable         | `switch`                                  |
| Different behavior for payment statuses | `switch`                                  |
| Error checking and early return         | Usually `if`                              |

সঠিক পছন্দ নির্ভর করে readability এবং business logic-এর ওপর।

## 11. What Is `fallthrough`?

Go-তে matching case execute করার পর সাধারণত switch থেকে বেরিয়ে যায়। `fallthrough` ব্যবহার করলে পরের case-এর body-ও execute হয়, condition match করে কি না তা পরীক্ষা না করেই।

```go
package main

import "fmt"

func main() {
    number := 1

    switch number {
    case 1:
        fmt.Println("One")
        fallthrough

    case 2:
        fmt.Println("Two")

    default:
        fmt.Println("Other")
    }
}
```

**Output:**

```text
One
Two
```

এখানে `number` হলো `1`, তবুও `fallthrough`-এর কারণে case 2-এর body execute হয়েছে।

**Senior Engineer Tip:** সাধারণ business logic-এ `fallthrough` খুব কমই প্রয়োজন হয়। এটি control flow বোঝা কঠিন করতে পারে, তাই পরিষ্কার বিকল্প থাকলে সেটি ব্যবহার করবে।

## 12. Type Switch

কখনো interface-এর ভেতরে কোন ধরনের value আছে, তা যাচাই করতে হয়। তখন type switch ব্যবহার করা যায়।

```go
package main

import "fmt"

func describe(value any) {
    switch v := value.(type) {
    case string:
        fmt.Println("String:", v)

    case int:
        fmt.Println("Integer:", v)

    case bool:
        fmt.Println("Boolean:", v)

    default:
        fmt.Printf("Other type: %T\n", v)
    }
}

func main() {
    describe("Zamirul")
    describe(100)
    describe(true)
    describe(3.14)
}
```

**Output:**

```text
String: Zamirul
Integer: 100
Boolean: true
Other type: float64
```

### What Is `any`?

`any` হলো Go-তে `interface{}`-এর alias। এটি যেকোনো type-এর value ধারণ করতে পারে।

```go
func describe(value any)
```

এখানে function-টি যেকোনো type-এর argument নিতে পারে।

### How Type Switch Works

```go
switch v := value.(type)
```

- `value` হলো interface value।
- `value.(type)` শুধু type switch-এ ব্যবহার করা যায়।
- প্রতিটি `case` নির্দিষ্ট type পরীক্ষা করে।
- `v` matching case-এর মধ্যে সেই type-এর value হিসেবে ব্যবহার করা যায়।

**Production Tip:** `any` সুবিধাজনক হলেও নির্বিচারে ব্যবহার করলে compile-time type safety কমে যায়। সম্ভব হলে নির্দিষ্ট type বা interface ব্যবহার করবে।

## 13. Real-World Project — Ticket Booking Validation

এখন একটি ছোট business rule implement করব।

একটি event-এ ticket বুক করতে হলে:

1. Event active হতে হবে।
2. Quantity positive হতে হবে।
3. Requested quantity available stock-এর বেশি হতে পারবে না।
4. Payment status `paid` হতে হবে।

### Implementation

```go
package main

import (
    "errors"
    "fmt"
)

type BookingRequest struct {
    EventActive   bool
    Quantity      int
    Available     int
    PaymentStatus string
}

func ValidateBooking(req BookingRequest) error {
    if !req.EventActive {
        return errors.New("event is not active")
    }

    if req.Quantity <= 0 {
        return errors.New("quantity must be positive")
    }

    if req.Quantity > req.Available {
        return errors.New("not enough tickets available")
    }

    switch req.PaymentStatus {
    case "paid":
        return nil

    case "pending":
        return errors.New("payment is pending")

    case "failed":
        return errors.New("payment failed")

    default:
        return errors.New("invalid payment status")
    }
}

func main() {
    req := BookingRequest{
        EventActive:   true,
        Quantity:      2,
        Available:     10,
        PaymentStatus: "paid",
    }

    if err := ValidateBooking(req); err != nil {
        fmt.Println("Booking rejected:", err)
        return
    }

    fmt.Println("Booking validation successful")
}
```

**Expected Output:**

```text
Booking validation successful
```

### Code Review — Senior Engineer Perspective

ভালো দিকগুলো:

- Validation একটি function-এ রাখা হয়েছে।
- Invalid request-এর জন্য error return করা হয়েছে।
- Payment status-এর জন্য `switch` ব্যবহার করা হয়েছে।
- `main()`-এর logic সহজে পড়া যায়।

Production-এ যাওয়ার আগে আরও কিছু বিষয় বিবেচনা করতে হবে:

- Concurrent booking-এর সময় stock race condition এড়াতে database transaction বা atomic inventory strategy দরকার।
- Client-এর পাঠানো payment status সরাসরি বিশ্বাস করা যাবে না। Server-side payment record বা trusted payment provider থেকে যাচাই করতে হবে।
- Error-গুলোকে sentinel error বা typed error হিসেবে সাজানো যেতে পারে।
- Unit tests এবং integration tests যোগ করতে হবে।
- Validation সফল হলেই booking সম্পন্ন হয়েছে, এমন নয়।

**Remember:** Validation এবং booking execution দুটি আলাদা বিষয়। শুধু validation করে ticket reserve করা production system-এ নিরাপদ নয়।

## 14. Common Mistakes

### Mistake 1: Placing `else` Incorrectly

Go-তে `else` closing brace-এর একই statement-এর অংশ হিসেবে লিখতে হবে।

```go
if age >= 18 {
    fmt.Println("Adult")
} else {
    fmt.Println("Minor")
}
```

### Mistake 2: Incorrect Condition Order

Range conditions ভুলভাবে সাজালে সঠিক branch execute নাও হতে পারে।

### Mistake 3: Assuming Automatic `fallthrough`

Go-তে matching case-এর পরে সাধারণত switch থেকে বেরিয়ে যায়। প্রয়োজন ছাড়া `fallthrough` ব্যবহার করবে না।

### Mistake 4: Trusting Client Input for Security

`isAdmin`, `paymentStatus` বা `isPaid`-এর মতো client-supplied value সরাসরি authorization-এর ভিত্তি হিসেবে ব্যবহার করবে না। Server-side verification দরকার।
